# Programmes fournis avec l'émulateur

Seuls des programmes dont l'auteur a **explicitement autorisé la redistribution**
sont publiés ici. Un logiciel ancien ou « abandonné » n'est pas pour autant dans le
domaine public : ne pas ajouter de programme sans une autorisation vérifiable.

La liste affichée dans l'interface vient de [`index.json`](index.json).

| Fichier | Programme | Statut |
| --- | --- | --- |
| `ve2cuy-invaders.cmd`, `ve2cuy-invaders.cas` | VE2CUY Invaders (2026), VE2CUY | Écrit pour ce projet ([source](../../asm/invaders.asm)) |
| `seadragon.cmd` | Sea Dragon (1982), Wayne Westmoreland et Terry Gilman | Domaine public |
| `armored-patrol.cmd` | Armored Patrol (1981), Wayne Westmoreland et Terry Gilman | Domaine public |

## Source et autorisation

Fichiers extraits de la disquette distribuée par Matthew Reed
([trs-80.org](https://www.trs-80.org/games-by-wayne-westmoreland-and-terry-gilman.html),
archive `aigames.zip`, copie de la Wayback Machine). Le fichier d'origine
[`WESTMORELAND-README.TXT`](WESTMORELAND-README.TXT) contient la déclaration de
Wayne Westmoreland (1995) :

> The programs display copyright notices but I hearby release them into the
> public domain, do with them as you please.

La déclaration est signée par Wayne Westmoreland seul; Terry Gilman, coauteur, ne
l'a pas signée.

## Programmes volontairement exclus

La même disquette contient d'autres jeux, non publiés ici :

- **Defender / Eliminator, Donkey Kong, Zaxxon** : adaptations de jeux de Williams,
  Nintendo et Sega, dont les auteurs ne pouvaient pas céder les droits.
- **Tank Zone 2000** : version d'Armored Patrol encore très proche de Battlezone (Atari).
- **Rear Guard** : écrit sur commande d'Adventure International d'après le jeu d'un
  autre auteur; les droits ne sont peut-être pas ceux de Westmoreland.

## Compatibilité

Ces versions viennent d'une disquette TRSDOS. Au chargement, l'émulateur remplace
les appels de fichiers du DOS par des routines minimales : les meilleurs scores ne
sont pas conservés.
